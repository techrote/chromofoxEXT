# chromofoxEXT

Small, independently loadable browser extensions for Firefox and Chromium.

## Available in this repository

| Extension | Browsers | Purpose | Status |
| --- | --- | --- | --- |
| [Link QR Popout](extensions/link-qr-popout/README.md) | Firefox, Chrome/Chromium | Right-click a link and display its URL as a locally generated QR code in a popout window | Draft implementation; browser acceptance pending |

Extensions are kept in separate directories. See each extension's README for installation, permission rationale, and test instructions.
