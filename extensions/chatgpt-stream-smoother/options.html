ChatGPT Stream Smoother

Three independent models for softening streaming-output movement. No network requests or content capture.

Behaviour

Standard input buffer

New lines enter a visual lag buffer. The release speed is interpolated between your depth-to-speed limits; large backlogs catch up faster.

Example: 0:55, 1:100, 3:190, 6:350, 12:650.

Soft push

Each arriving line increases a ramped acceleration demand. Braking slows the canvas toward rest rather than abruptly changing velocity.

Animated line steps

Move one line at a time, with independently adjustable acceleration and deceleration intervals and velocity curves.

Disabled by default until you enable it. Manual scrolling interrupts smoothing; returning to the bottom allows resumption. Conversation text is never stored.
